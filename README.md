# 🚀 ERP Lite – Full Stack Application

A modern **Enterprise Resource Planning (ERP)** system built with a clean architecture and real-world features.

---

## 🛠️ Tech Stack

### 🔹 Frontend

* Angular
* TypeScript
* HTML5 & CSS3

### 🔹 Backend

* Spring Boot
* Java
* Spring Security + JWT

### 🔹 Database

* PostgreSQL

---

## ✨ Features

* 🔐 **Authentication System**

  * Login & Register
  * JWT-based secure authentication

* 👥 **Employee Management**

  * Add, Edit, Delete Employees
  * Search functionality
  * Pagination support

* 📊 **Dashboard**

  * Overview of employees, tasks, leaves

* 🧑‍💼 **Role-Based Access**

  * Admin / Employee roles
  * Protected routes using Angular guards

* ⚡ **Modern UI**

  * Clean dashboard layout
  * Responsive design

---

## 📁 Project Structure

```
erp-lite-fullstack/
 ├── backend/     # Spring Boot REST API
 ├── frontend/    # Angular Application
```

---

## ⚙️ Setup Instructions

### 🔹 Backend (Spring Boot)

```bash
cd backend
mvn spring-boot:run
```

➡️ Runs on: `http://localhost:8080`

---

### 🔹 Frontend (Angular)

```bash
cd frontend
npm install
ng serve
```

➡️ Runs on: `http://localhost:4200`
